<p>This Android application captures incoming calls and SMS messages, and forwards the data to a Bark server, via email, or through a webhook. You can receive notifications on other devices using the Bark app, email, or by setting up a custom webhook.</p><p><br><b>Features:</b></p><ul><li>Capture incoming calls and SMS messages.</li><li>Forward call and SMS information to a Bark server.</li><li>Send email notifications with call and SMS information.</li><li>Forward call and SMS information to a custom webhook endpoint.</li><li>Receive notifications on other devices using the Bark app.</li></ul><p>Set up your Bark server by following the instructions provided in the <a href='https://github.com/Finb/bark-server/blob/master/README.md' target='_blank' rel='nofollow noopener'>Bark Server GitHub repository</a>. You can also use the <a href='https://bark.day.app/' target='_blank' rel='nofollow noopener'>Bark public server</a> if you don't want to set up your own. However, it is not recommended considering privacy.</p>
